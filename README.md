# yj_study_setdnsip
테스트용 IP 자동 변경 스크립트 (GUI 버전)

버그가 있을 수 있습니다.

- Windows OS 용 스크립트
- ip 입력 value Local에 저장. 재 실행시 입력 필요 없으며, 수정 필요할 시 수정 기능 제공
- 세팅 후 DNS cache flush 처리.
